# 📝 История изменений

Все заметные изменения SysDiff документируются в этом файле. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют Semantic Versioning.

## [Не выпущено]

### Планируется

- импорт и экспорт `.sdshot`;
- загрузка пользовательских профилей;
- автоматическое маскирование `%USERPROFILE%`;
- полная локализация RU/EN;
- экспериментальный live monitor.

## [0.2.0] — 2026-08-01

### Добавлено

- `FirewallProvider` с правилами, профилями, портами, адресами, программами и службами;
- `InstalledAppsProvider` для uninstall-разделов HKCU/HKLM в 32- и 64-битных представлениях;
- `DriversProvider` с состоянием, путём, SHA-256, версией и сведениями о подписи;
- `CertificatesProvider` для пользовательских и машинных хранилищ без экспорта приватных ключей;
- изолированный read-only PowerShell JSON-адаптер с тайм-аутом;
- правила важности для Firewall, приложений, драйверов и сертификатов;
- расширенные правила подавления кэшей и изменений только текущего состояния;
- ожидание дерева дочерних процессов в `watch`;
- параметр `watch --timeout`;
- тесты правил важности версии 0.2.0.

### Изменено

- профили `minimal`, `standard` и `full` расширены новыми провайдерами;
- версия создаваемого снимка и portable-пакета обновлена до `0.2.0`;
- документация провайдеров и команд актуализирована.

### Безопасность

- найденные команды удаления, пути драйверов и параметры Firewall остаются только данными;
- приватные ключи сертификатов не читаются и не экспортируются;
- тайм-аут `watch` не завершает исследуемые процессы автоматически.

## [0.1.0] — 2026-08-01

### Добавлено

- слоистая архитектура Domain/Core/Storage/Providers/Reporting/CLI;
- снимки файловой системы, реестра, служб, задач, автозагрузки и окружения;
- SQLite-хранилище;
- движок сравнения Added/Removed/Modified;
- оценка важности и фильтрация шума;
- консольный, JSON, Markdown и автономный HTML-отчёт;
- базовый TUI;
- режим `watch`;
- portable-сборка для win-x64;
- unit-тесты, GitHub Actions и русская документация.
