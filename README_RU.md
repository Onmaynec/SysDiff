## 🚀 SysDiff 0.2.0

В версии 0.2.0 добавлены:

- 🧱 анализ правил Windows Firewall;
- 📦 снимки установленных приложений;
- ⚙️ сведения о системных драйверах, SHA-256 и подписях;
- 🔐 снимки хранилищ сертификатов без экспорта приватных ключей;
- 👀 ожидание дерева дочерних процессов в `watch`;
- ⏱️ безопасный тайм-аут наблюдения;
- 🧹 дополнительные правила фильтрации системного шума;
- 🚦 новые объяснимые правила важности.
