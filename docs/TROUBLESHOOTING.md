# 🧰 Решение проблем

## `Access denied`

Запустите терминал от имени администратора или используйте более узкий профиль. SysDiff сохраняет частичный снимок и отмечает недоступные провайдеры.

## Снимок слишком большой

- используйте `minimal`;
- уменьшите корни файловой системы;
- добавьте исключения;
- используйте `Smart`, а не `Full`;
- снизьте `maximumDepth` и `maximumArtifacts`.

## Очень много временных файлов

Используйте:

```powershell
sysdiff compare before after --noise Balanced
sysdiff compare before after --noise Strict
```

Для полного расследования:

```powershell
sysdiff compare before after --noise Raw
```

## Установщик завершился, но изменения не видны

Некоторые установщики запускают дочерние процессы и завершают основной. В 0.2.0 включите ожидание дерева процессов:

```powershell
sysdiff watch .\Setup.exe --wait-for-children --timeout 900
```

Очень короткоживущий процесс может завершиться между опросами Toolhelp. Для сложного установщика используйте ручной режим:

```powershell
sysdiff watch --no-launch
```

## `watch` достиг тайм-аута

SysDiff не завершает исследуемые процессы автоматически. Он создаёт итоговый снимок, сохраняет отчёт и возвращает код `7`. Проверьте, остались ли процессы работающими, и при необходимости повторите наблюдение с большим `--timeout`.

## Firewall или драйверы завершились как `Partial`

Проверьте:

- доступность `powershell.exe`;
- наличие модуля `NetSecurity` для Firewall;
- доступность WMI/CIM;
- права текущего пользователя;
- корпоративные политики PowerShell;
- результат `sysdiff doctor`.

SysDiff запускает только встроенные read-only сценарии без профиля пользователя. Ошибка адаптера не останавливает другие провайдеры.

## Сертификаты отображаются как недоверенные

Проверка цепочки в 0.2.0 выполняется локально, с отключённой сетевой загрузкой промежуточных сертификатов и проверкой отзыва. Результат может отличаться от интерактивной проверки Windows в сети.

## Подпись драйвера `MissingOrInvalid`

Это означает, что SysDiff не смог прочитать сертификат подписи из файла. Значение не является окончательным вердиктом: дополнительно проверьте файл средствами Windows и Authenticode.

## Задачи планировщика недоступны

Проверьте:

- запуск в Windows 10/11;
- службу Task Scheduler;
- права текущего пользователя;
- результат `sysdiff doctor`.

## База SQLite повреждена

1. Закройте все экземпляры SysDiff.
2. Создайте резервную копию каталога данных.
3. Сохраните `sysdiff.db`, `sysdiff.db-wal`, `sysdiff.db-shm`.
4. Не удаляйте файлы до анализа.
5. Для нового чистого запуска временно переименуйте каталог данных.

Автоматическое восстановление повреждённой базы пока не реализовано.

## Отчёт содержит личные данные

Не публикуйте его. Создайте копию, удалите чувствительные строки и сообщите о месте утечки без реальных значений.
