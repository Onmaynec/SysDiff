# 🛡️ Безопасность реализации

## Модель угроз

SysDiff читает большое количество недоверенных системных строк: пути, XML задач, значения реестра, имена служб и данные будущих импортируемых снимков. Любая такая строка считается данными, а не командой.

## Реализованные меры

- параметризованные SQL-запросы;
- SQLite foreign keys и транзакции;
- HTML-экранирование в браузере;
- JSON-сериализация без генерации исполняемого кода;
- маскирование чувствительных значений реестра;
- потоковое чтение файлов;
- ограничение глубины, размера и количества объектов;
- запрет рекурсивного обхода reparse point;
- отсутствие автоматического rollback;
- явное уведомление о неполных правах.

## Правила для провайдеров

Провайдер не должен:

- запускать команду из реестра, службы или задачи;
- извлекать приватные ключи;
- изменять исследуемую систему;
- подавлять исключения без диагностического сообщения;
- записывать секреты в лог.

## Импорт снимков

Формат `.sdshot` запланирован, но ещё не реализован. До его появления нельзя считать ZIP или JSON из внешнего источника доверенным. Будущая реализация должна проверять:

- ZIP Slip;
- общий и распакованный размер;
- контрольные суммы;
- версию схемы;
- дублирующиеся пути;
- символические ссылки;
- отсутствие выполняемых действий при импорте.
