# 🔴 Live Monitor

Live Monitor — экспериментальный режим SysDiff 0.3 для наблюдения за кратковременными процессами и сетевыми endpoints между обычными снимками.

## Процессы

```powershell
sysdiff live process --duration 60
sysdiff live process --duration 120 --root-pid 1234
```

SysDiff периодически читает список процессов Windows и сравнивает соседние состояния.

События:

- `Started` — PID появился;
- `Stopped` — PID исчез;
- Parent PID сохраняется, когда доступен;
- путь исполняемого файла маскируется через `%USERPROFILE%`.

Режим не внедряет код, не открывает процессы для записи и не завершает их.

## Сеть

```powershell
sysdiff live network --duration 60
```

Собираются изменения:

- активных TCP connections;
- UDP listeners;
- локальных и удалённых endpoints;
- TCP state.

Содержимое пакетов, HTTP-запросы, DNS payload и учётные данные не перехватываются.

## Ограничения

- используется polling, поэтому очень короткое событие может быть пропущено;
- PID сетевого endpoint в версии 0.3 не гарантируется;
- PID может быть повторно использован Windows после завершения процесса;
- журнал ограничен 100 000 событиями;
- длительность ограничена 86 400 секундами.

## Отмена

`Ctrl+C` корректно отменяет наблюдение. SysDiff не оставляет драйверы, службы или фоновые агенты.
