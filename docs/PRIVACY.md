# 🕶️ Конфиденциальность

Снимки системы потенциально содержат чувствительные данные: пути профиля, названия программ, структуру реестра, имена служб и команды запуска.

## Принципы

- не сохранять имя пользователя и компьютера без необходимости;
- не экспортировать приватные ключи;
- маскировать значения, похожие на секреты;
- не публиковать необработанные снимки;
- хранить данные локально;
- давать пользователю понятный путь к базе и отчётам.

## Маскирование секретов

RegistryProvider проверяет имя значения на фрагменты:

```text
password
token
secret
credential
apikey
api_key
privatekey
```

Вместо исходного значения сохраняется:

```text
<redacted>
```

Для определения факта изменения сохраняется SHA-256.

## Перед отправкой отчёта

Проверьте:

- пути `C:\Users\...`;
- имена установленных программ;
- команды запуска;
- сетевые адреса;
- названия внутренних служб;
- пользовательские переменные окружения.

Автоматическая замена пользовательского профиля на `%USERPROFILE%` описана в конфигурации, но в MVP ещё не применяется ко всем провайдерам. Публичный отчёт следует просматривать вручную.
