# 🕶️ Конфиденциальность

Снимки и live-журналы могут содержать пути, имена программ, сертификаты, сетевые адреса и команды запуска. SysDiff хранит данные локально и применяет redaction до записи снимка.

## Автоматическое маскирование путей

`PrivacyRedactor` заменяет:

```text
C:\Users\Alice\AppData\Local\Demo
```

на:

```text
%USERPROFILE%\AppData\Local\Demo
```

Маскирование применяется к `Identity`, `DisplayName`, свойствам артефактов, предупреждениям провайдеров и путям live process monitor.

## Секреты реестра

Значения с именами, содержащими `password`, `token`, `secret`, `credential`, `apikey`, `api_key` или `privatekey`, сохраняются как `<redacted>`. SHA-256 позволяет определить факт изменения без хранения исходного секрета.

## Machine fingerprint

Для межмашинного сравнения создаётся SHA-256 fingerprint. Открытое имя компьютера не сохраняется. Fingerprint предназначен только для определения, получены ли снимки на одном источнике.

## Сертификаты и сеть

- приватные ключи сертификатов не читаются и не экспортируются;
- live network monitor не захватывает payload пакетов;
- investigation bundle не включает сырые логи;
- `.sdshot` хранит только данные выбранного снимка.

## Плагины

Внешний provider работает с правами процесса SysDiff и может самостоятельно читать данные Windows. Загружайте DLL только из доверенного источника и только через явный `--plugin`.

## Перед публикацией

Проверьте:

- названия внутренних программ и служб;
- сертификаты и издателей;
- IP-адреса и маршруты;
- пользовательские переменные;
- данные внешних providers.

Автоматическое маскирование снижает риск, но не заменяет ручную проверку отчёта.
