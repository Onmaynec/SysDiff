# 📊 Отчёты

## Console

Подходит для терминала и быстрого анализа:

```powershell
sysdiff compare before after
```

Изменения группируются по провайдерам, важные свойства показываются сразу.

## JSON

Машинно-читаемый формат:

```powershell
sysdiff compare before after --format json --output report.json
```

Содержит метаданные снимков и полный объект `ComparisonResult`.

## Markdown

Удобен для Issues, pull request и заметок:

```powershell
sysdiff compare before after --format markdown --output report.md
```

Перед публикацией необходимо проверить конфиденциальные данные.

## HTML

Автономный файл без CDN:

```powershell
sysdiff compare before after --format html --output report.html
```

Возможности:

- поиск;
- фильтр по провайдеру;
- фильтр по важности;
- сводные показатели;
- раскрывающиеся карточки;
- сравнение свойств;
- тёмная и светлая тема;
- печать;
- адаптивная ширина.

Системные значения вставляются через безопасное экранирование JavaScript-функцией `esc`. Отчёт не загружает внешние ресурсы.

## Уровни важности

- `Info` — обычное состояние или слабый сигнал;
- `Low` — настройка или файл данных;
- `Medium` — исполняемый файл, PATH, значимое окружение;
- `High` — служба, задача, автозагрузка;
- `Critical` — чувствительный Winlogon или служба из пользовательской/временной директории.

Уровень важности не является вердиктом о вредоносности.
