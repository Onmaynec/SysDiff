# SysDiff 0.8.0 — Compatibility Center

Релиз делает совместимость переносимых `.sdshot` наблюдаемой и проверяемой до импорта. SysDiff больше не сводит проверку версии к одному условию внутри `ImportAsync`: формат получает отдельную policy model, inspection API и CLI.

## Главное

- `sysdiff compatibility status|matrix` показывает поддерживаемые версии;
- `sysdiff compatibility inspect|verify <file.sdshot>` проверяет архив без записи в SQLite;
- JSON-вывод подходит для CI и incident workflows;
- более новая schema получает `RequiresNewerSysDiff` и не импортируется;
- устаревшая schema без handler получает `UnsupportedLegacy`;
- повреждённый архив получает `Invalid`;
- совместимый архив получает `Compatible` и `canImport=true`.

## Усиление `.sdshot`

- проверка всех ZIP paths;
- лимит количества entries;
- отказ от дубликатов обязательных файлов;
- точная проверка отдельных SHA-256 строк;
- проверка JSON parsing;
- проверка format identifier;
- проверка Snapshot ID между manifest и payload;
- проверка schema version между manifest и payload;
- единая policy для inspection и реального import.

## Совместимость

Текущий `.sdshot` остаётся container format `1` со snapshot schema `1`. Релиз не объявляет их стабильной публичной схемой 1.0 и не изменяет существующие SQLite tables.

Снимки 0.3–0.7 с format/schema `1` продолжают импортироваться. Snapshot metadata новых экспортов содержит версию `0.8.0`.

## CLI

```powershell
sysdiff compatibility status
sysdiff compatibility status --json
sysdiff compatibility inspect .\before.sdshot
sysdiff compatibility inspect .\before.sdshot --json
```

Exit code `4` зарезервирован для несовместимого или повреждённого переносимого формата.

## Безопасность

Inspection read-only: она не создаёт snapshot в SQLite, не меняет baseline, не связывает данные с active case и не выполняет migration автоматически.

Неизвестные данные не отбрасываются с последующим сохранением урезанного snapshot. Для будущих breaking versions потребуется явный migration handler с backup, dry-run и integration fixtures.
