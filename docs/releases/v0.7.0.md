# SysDiff 0.7.0 — Release Channel

Первый полноценный production-релиз SysDiff с автоматическим тегом, GitHub Release assets, проверяемым manifest и встроенным безопасным updater.

## Главное

- официальный tag `v0.7.0` указывает на squash merge-коммит релиза;
- portable `win-x64` ZIP публикуется как GitHub Release asset;
- вместе с архивом публикуются `.sha256` и `release-manifest.json`;
- ZIP и manifest получают GitHub artifact provenance attestations;
- Cyber Console получила Update Center;
- доступны команды `update check`, `status`, `download`, `install`, `settings`, `clear-cache`;
- auto-check stable channel включён по умолчанию;
- auto-download выключен по умолчанию;
- auto-install отсутствует: установка всегда требует `--yes` или подтверждения в TUI.

## Безопасность обновления

- только HTTPS и официальный GitHub host;
- строгая связь version → tag → asset URL;
- проверка размера и SHA-256;
- защита от ZIP path traversal и чрезмерной распаковки;
- staged EXE проверяется командой `--version`;
- работающий EXE не перезаписывается напрямую;
- helper ждёт завершения текущего PID;
- текущая версия копируется в backup;
- ошибка post-install verification запускает rollback;
- пользовательские snapshots, SQLite, cases и reports не удаляются.

## Authenticode

Сборка 0.7.0 пока не подписана Authenticode-сертификатом. Manifest явно содержит `unsigned: true`. GitHub provenance и SHA-256 подтверждают происхождение pipeline и целостность assets, но не выдаются за code-signing подпись.

## Обновление из 0.7+

```powershell
sysdiff update check
sysdiff update download
sysdiff update install --yes --restart
```

Версии до 0.7.0 обновляются вручную: скачайте portable ZIP на этой странице и распакуйте его в новый каталог.
