# SysDiff 0.10.0 — Schema Contract

Релиз фиксирует первый стабильный публичный JSON Schema Contract v1 для переносимых данных SysDiff.

## Главное

- JSON Schema Draft 2020-12 для snapshot, comparison report и investigation bundle manifest;
- embedded schema catalog внутри `SysDiff.Storage`;
- CLI `schema list|matrix|show|validate|verify`;
- machine-readable validation statuses;
- golden fixtures с additive extension fields;
- required/type/enum/UUID/date/SemVer validation;
- future schema guard;
- documented deprecation и breaking-change policy.

## Команды

```powershell
sysdiff schema list
sysdiff schema list --json
sysdiff schema show snapshot
sysdiff schema validate snapshot .\snapshot.json
sysdiff schema validate comparison .\report.json --json
sysdiff schema validate bundle .\manifest.json --json
```

## Public schemas

```text
schemas/public/v1/
├── snapshot.schema.json
├── comparison-report.schema.json
└── investigation-bundle-manifest.schema.json
```

Все контракты используют `additionalProperties: true`. Unknown additive fields не ломают старый reader.

## Writer changes

Comparison JSON report теперь содержит:

- `format`;
- `formatVersion`;
- `schemaVersion`;
- `sysDiffVersion`.

Investigation bundle manifest:

- получает `schemaVersion: 1`;
- записывает текущую producer version вместо hard-coded `0.3.0`;
- self-validates до ZIP packaging.

Snapshot contract сохраняет исторический PascalCase, чтобы не менять shape `.sdshot` 0.3–0.9.

## Golden fixtures

CI валидирует:

- snapshot v1;
- comparison report v1;
- bundle manifest v1;
- неизвестные extension fields;
- missing required fields;
- invalid enum values;
- future schema version rejection.

## Compatibility policy

Additive optional fields разрешены внутри schema v1. Breaking changes требуют schema major 2, нового `$id`, migration guide, fixtures и explicit compatibility tests.

Продукт остаётся pre-1.0: stable public data contract не означает завершение всех operational requirements SysDiff 1.0.

## Packaging

Portable ZIP включает:

- `SCHEMA_CONTRACT.txt`;
- `schemas/public/v1/*.schema.json`;
- `schema-fixtures/v1/*.json`;
- существующие migration, compatibility и update guides.

## Release engineering

Release gate проверяет:

- полный Core/Providers/CLI test suite;
- embedded schema resources;
- all golden fixtures через published EXE;
- self-contained `win-x64` package;
- SHA-256 и release manifest;
- provenance attestations;
- опубликованные GitHub Release assets.
