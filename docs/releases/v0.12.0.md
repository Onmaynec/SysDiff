# SysDiff 0.12.0 — Scale Lab

Релиз добавляет bounded-memory обработку больших artifact datasets и измеримый performance regression gate.

## Главное

- `sysdiff scale matrix|synth|sort|compare|benchmark`;
- aliases `large` и `stream`;
- SysDiff Artifact NDJSON v1;
- synthetic generator до 10 000 000 artifacts;
- external chunk sort;
- PriorityQueue k-way merge;
- streaming identity merge-join;
- NDJSON change output;
- managed heap, working set и throughput telemetry;
- machine-readable benchmark result;
- exit code `10` для performance regression.

## Million-object CI gate

Dedicated workflow выполняет:

```text
artifacts:          1 000 000
modified expected: 1 000
managed limit:      256 MiB
throughput floor:   1 000 artifacts/sec
```

Workflow публикует artifact `scale-benchmark-1000000`:

- `scale-benchmark.json`;
- `console.json`;
- `scale-changes.ndjson`.

## Memory model

- generator держит один artifact;
- sorter держит один batch и cursor на chunk;
- compare держит одну before/after пару;
- writer держит одну change record;
- result содержит counters, а не коллекцию изменений.

## External sort

Input делится на batches, каждый batch сортируется и записывается во временный chunk. K-way merge строит итоговый ordered stream и обнаруживает duplicate identities. Output публикуется атомарно.

## Streaming comparison

Оба input читаются последовательно. Identity merge-join определяет Added, Removed, Modified и Unchanged. По умолчанию в report записываются только changes.

## Совместимость

- product version: `0.12.0`;
- public Schema Contract: `1`;
- Scale NDJSON format: `1`;
- `.sdshot` format/schema: `1`;
- SQLite `user_version`: `9`.

Scale NDJSON является operational stream и не заменяет public portable JSON schemas.

## Безопасность

- line limit 4 MiB;
- synthetic count limit 10 000 000;
- invalid JSON и missing identity отклоняются;
- duplicate identities блокируют sort/compare;
- unsorted comparison input требует `scale sort`;
- input не изменяется;
- output создаётся через temporary file и atomic move;
- regression gate блокирует CI отдельным exit code.

## Packaging

Portable ZIP включает `SCALE_LAB.txt` вместе с Legacy Bridge, Schema Contract, migration, compatibility и update guides.

## Ограничения

Обычный `sysdiff compare` сохраняет severity/noise/move heuristics, но materialize snapshot из SQLite. Scale Lab предоставляет отдельный file-stream path; прямой provider-to-storage streaming и paginated HTML/Markdown остаются следующими этапами.
